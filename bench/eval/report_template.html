Speed

Latency and throughput over HTTP

Measured from a client on the same host over keep-alive connections, which is how real HTTP clients behave. The original server sent headers and body as two writes with Nagle's algorithm on, which stalled every keep-alive response by about 40 ms. The current server writes once with TCP_NODELAY; the "before" numbers are kept for comparison.
